Cela Documentation

Maintained by Michael Wallis — Audio Programmer

Overview

Cela is based off of Conway's Game of Life a Cellular Automita. Each Cell is represented by a MIDI value which plays ON if the cell is alive and plays OFF if the cell is dead. This allows for a unique repeatable but still unpredictable melody creation.

Created at Queen Mary University of London, for the IDMT Module.
